# 证明核验记录

日期：2026-10-14。范围：本轮书面证明的内部核查与可复现诊断。没有执行隔离代理复核或外部形式化验证。

## 目标与假设

主目标保持为：独立平稳 bounded 奖励、外生永久到达、每轮一次样本，可靠报告全部相对 epsilon-近优候选的 C/D/V 划分；收益用期望 pseudo-regret，及时性用高概率累计未决臂时间。报告在本轮观测后给出。eta 是不要求精确处理的边界带宽，不是删去边界内环境的假设。

特定定理额外限制均在正文陈述：Bernoulli 下界族、固定参数区间、独立符号先验、多批次递增 benchmark、充分长窗口、预先选择的检查点精度。主 CP-UCB-AA 不知道真实最佳臂位置；P1 的已知角色构造单独标明。T7 只在最终停止到达且边界分离时证明几乎必然最终完整。

## 证明接口与状态

| 接口 | 已核查的数学内容 | 状态/边界 |
|---|---|---|
| 报告覆盖 | Hoeffding、潜在前缀或固定检查点并集、非空/坏事件处理 | 自包含；不把旧样本条件化为新样本 |
| 序贯信息 | 同一动作核消去、有界停止、有限双向 KL | 自包含；不能假定随机计数独立于均值 |
| T1 面积到信息 | 单查询未决概率、凸截断二元 KL、坏事件 delta W | 有效下界松弛，未证明一般可达 |
| T2 广播/共同影响 | 从期望计数确定难臂，同一参考环境贯穿时间 | 期望及常数概率下界 |
| L2 队列面积 | 到达先于服务，显式扣除忙期末轮 | 精确整数边界已检查 |
| L3 部分同时恢复 | 适应性后验因子化、乘积正确概率、似然漂移、小 m 与小 delta | 不依赖计数独立；统计尺度有既有文献先例 |
| T4 多窗口 | 同一乘积先验，面积成功迫使足够窗口完成，样本不重复收费 | 异质凸下界；齐次明确下界 |
| T5 共享更新 | 新参照下界加旧上界退休整个前批，旧参照上界被新水平压住 | 充分长窗口族；任意重叠不在此闭合 |
| T5 期望 regret | 配额前样本在出生窗口；UCB 超配额计数；逐轮可求和坏概率 | 不需要标签覆盖事件成立，无 delta T 遗漏 |
| T6 匹配 | 相同 epsilon/eta/delta/日程，显式 H，面积预算分别 V/8、9V/8 | 快速端匹配；宽松端只有 upper |
| T7 强一致性 | 持久计数、可纠错原始区间、可数 Hoeffding/Borel–Cantelli | 最终有限臂，不宣称无限到达全体最终确定 |
| T8 最坏面积 | 静态批量 lower 对接任意到达 upper；K=2,T=1 及取整 | 相同风险模式；不等同于逐日程复杂度 |
| C5/T9 量词 | 终点总臂数类 vs 单一无限日程；困难环境允许随终点变 | 不能偷换成单一环境每个终点都困难 |
