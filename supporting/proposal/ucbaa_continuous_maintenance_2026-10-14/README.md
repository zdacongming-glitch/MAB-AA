# UCB-AA：持续相对近优集合维护研究包

版本：2026-10-14 / v1.0。

## 阅读入口

`持续集合维护_理论与完整证明.md` 是本轮主要交付，包含模型、同一可靠性—累计未决量协议、全部书面证明、适用范围和逐项创新性评价。编号为 T1–T9、L1–L3、C1–C5、P1；编号数量不等于独立创新数量。

本包不修改原 UCB-AA 稿件，也不将独立 temporal-geometry 论文的谱 minimax 结果计作新贡献。

最值得先阅读：第 4 节 T2（新臂不确定性对旧报告的共同影响）、第 8–10 节 T4–T6（相同面积协议下的必要成本与可执行两端权衡）、第 13–14 节 T8–T9（最坏维护面积及临界突发反例）。第 18 节是本轮实际成果的创新性评价。

## 文件

- `持续集合维护_理论与完整证明.md`：完整理论、证明、算法和边界。
- `cp_ucb_aa.py`：主算法 CP-UCB-AA 的恒定精度可执行版本，Python 3.10+，只使用标准库。类不接收均值、最佳臂身份、未来日程或终点。非齐次事前精度序列在证明中给出，未在此类接口中另行实现。
- `diagnostics.py`、`diagnostics-results.json`：代数、队列、区间更新的有限/随机诊断及实际输出；不是普遍证明或算法对比实验。
- `implementation-sanity.json`：一次 20,000 轮 Bernoulli 集成运行。该运行不是主定理族、不是强基线对比、不是频率覆盖验证。
- `proof-audit.md`：假设、接口、反例检查和仍未闭合的任务。
- `assessment-record.json`：本轮逐结果创新性判断、执行范围与实际次数；只有一次当前上下文评价，没有独立重复均值/方差。
- `evidence-manifest.json`：输入版本、规则版本、主要文献和交付文件摘要。

## 复现诊断

在此目录运行：

```bash
python diagnostics.py --out diagnostics-results.json
python cp_ucb_aa.py --out implementation-sanity.json
```

可以重新得到确定种子下的诊断和集成记录。不同 Python 浮点实现末位可能不同。算法调用必须交替进行 `choose(new_arm_labels)` 和 `observe(reward)`；每轮观测后调用 `report()` 得到 C、D、V。

## 理论状态

已给出：一般信息下界、共同参考环境下的维护队列下界、一般可执行保底上界、部分同时恢复引理、明确多次更新族上的快速维护匹配界及宽松服务上界、最终有限臂强一致性、最坏维护面积匹配，以及突发到达反例。

尚未给出：任意重叠到达与异质边界距离下的完整 regret–未决面积 Pareto 前沿；主算法相对于保留历史的 ALL-epsilon / FAREAST 自然适配版的独占优势；独立代理复核、形式化证明或外部同行核验。

特别注意 T6：快速预算和宽松预算使用同一个实例族和同一个错误概率、边界精度，但允许的面积不同；快速界在显式选择的窗口长度族上匹配，宽松端只给可达上界。不应扩大为所有窗口长度上的完整最优性。
