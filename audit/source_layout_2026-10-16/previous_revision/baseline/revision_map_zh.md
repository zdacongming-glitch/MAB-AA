## 记号与名词的沿用边界

共享对象以原稿 Problem Formulation 为准：全体臂 $\mathcal{A}$、可用臂集 $\mathcal{A}_t$、到达时刻 $\tau_i$、奖励均值 $r_i$、经验均值 $\hat r_i(n)$、最好均值 $r^*(t)$、gap $\Delta_i(t)=r^*(t)-r_i$、策略 $\pi$ 及历史 $H_{t-1}$。$R_T$ 沿用 cumulative dynamic regret 的名称，其期望写作 $\mathbb E R_T$。沿用 MAB-AA、arrival information discrepancy（AID）和 drifting benchmark（DB）三个名称。原稿局部混用的 $A_t$ 与 $\mu_i$ 不作为统一基准。

原数值部分已用 $K_t=|\mathcal{A}_t|$，本稿保留这一实际臂数记号，并以 $N_i(t)$ 表示实际累计拉取数。两者分别区别于原算法已知的轮次到达数量上界 $K(m)$、阶段目标 $n_p$ 和轮内拉取数 $N^\pi_{i,m}$。物理时刻 $t$、确定终点 $T$ 不改成原算法轮 $m$ 或随机完成时间 $T_0(\pi)$，也不将原 $T=\mathbb E T_0(\pi)$ 的定义移植到新结果。

新增统计任务使用独立记号：真实相对近优集合 $\mathcal G_t^\varepsilon$，正认证、负认证与未决报告集 $\mathcal P_t,\mathcal N_t,\mathcal V_t$，累计未决面积 $\mathcal U_T(\eta)$；最好均值的置信界为 $\underline r^*(t),\overline r^*(t)$。原算法的 active set $B_m$ 与 surviving set $C_m$ 仍只用于原算法，不能用来重命名这些报告集合。报告负认证不等于原算法的永久淘汰；pre-elimination 与 formal elimination 也不作为 checkpoint 服务的同义词。

## 必须撤回或重写的主张

1. **问题和 comparator 的首次性。** 固定有限前缀可以嵌入 sleeping bandit，平稳均值排序比较器逐时等于当前可用最优。Ballooning 文献已有永久到达及该 regret。不能再把这些当首创，也不能说普通固定臂方法一概无法适配。
2. **两项 regret 分解的解释。** $D_M=R_{T_0}-R_M$ 是定义，但通常含接纳延迟与旧臂误删损失。原 Proposition 1 用到达改善的暴露面积代替整个 $D_M$ 不成立。第 2、3 节保留三项恒等式；覆盖事件上证明已接纳最好臂不会丢失，失败事件另计，接纳延迟始终显式保留。
3. **$G_3$ 的末期 gap 压缩。** 可比的是 $\widetilde\Delta_{\widetilde m_i}$ 与 $\Delta_i(m_i)$，不能换成 $\widetilde\Delta_{m_i}$。撤回原 Corollary 1、Theorem 2 和 online 结论的这一路证明。新的实际样本计数上界不使用该步；不能把中间不等式的反例夸大成最终速率或原算法必然不可能成立。
4. **随机淘汰链。** 固定链的交集概率上界取最大值不能控制观测所选链的并集。修复证明改用覆盖全部实际比较前缀的单一置信事件，不保留原链最大概率论证。
5. **最优臂定义与实际比较规则。** 活跃集最优与全部已接纳最优分别定义；用原两阶段实际比较证明覆盖事件上后者保留，不调用算法没有执行的已删除参照。只改最优臂名字不足以修复旧证明。
6. **辅助完成阶段的 anytime 解释。** 旧 $T_{\mathrm{aux}}$ 与实际 $T_{\mathrm{act}}$ 未证明可比。$M_\ell=2^\ell$ 使末期样本规模含 $4^{2^\ell}$，原论证撤回。新增重启按真实采样预算 $1,2,4,\ldots$，最后阶段在实际终点截断，并保留各阶段接纳延迟；不宣称跨阶段保留统计量。
7. **旧上界与旧下界匹配。** 内生随机检查点与确定物理终点不同；相同平方根外形不等于匹配。同质逐级抬升构造受有界均值制约，其块数须为 $O(T^{1/3})$。
8. **由大上界推出算法线性 regret。** 补充中 NE 或剧烈 gap 场景的大上界不能直接证明真实 regret 大。需要直接动作/损失下界。原附录已经承认一个此类界可能不紧，应保留这种谨慎。
9. **小 active set 就代表低资源或正确筛选。** 未接纳、未观察、统计排除与当前未决是不同状态。没有实际内存/运行成本测量，就不写实测资源优势。
10. **无条件或普遍数值优越。** 原图对 Growing MOSS 有明显失败场景；不能概括为“普遍更低 regret”或一律“只付少量代价”。

## 原数值证据、新数值证据与尚未完成的验证
