# 本轮审计、路线状态与未闭合接口

## 实际完成的核验

目标协议保持为期望 regret 与联合高概率标签/面积。主模型不增加内生到达、奖励漂移、已知真均值或可免费预览未来。

1. 定理 1 在同一奖励均值向量、相同终点/预算/最终臂数的两条日程上工作。过去不可区分性只用于第 h 轮以前；新参照信息没有被提前使用。late 截止时刻 a+1 是由累计面积推出，不是额外任务。两日程分别可行的策略均用完整模型有效区间而非已知性能均值作标签。
2. 定理 2 保留完整停止历史的后验因子化，不声称随机样本数相互独立。非负漂移 f(e) 避免减去全部 m；小 s、s=1 与小 δ 均在同一证明内。SymPy 独立检查 f''=1/[e²(1-e)²]。
3. 定理 3 只保存候选在有效窗口内首次确定标签；窗口后的负报告不伪装成原符号恢复。下界仍计入窗口后可能编码原符号的所有观测，每次这种候选采样仍有至少 ε/2 的 regret。
4. ABM 的粗数据可用于选择细任务，但新细置信预算只用于激活后的新观测块。避免对数据选择后的旧前缀重新使用固定时刻 Hoeffding。所有旧数据仍保留在收益统计量及已有粗报告中。
5. ABM 的工作队列与 regret 上界在坏报告路径也定义良好；服务次数有路径上配额限制，普通 UCB 用可求和坏轮界。没有遗漏 δT。
6. ABM 选细候选数 s(a) 的公式是性能类校准，不伪装成只输入 a 就自动知道 m,H。面积匹配包含显式 R0；固定 J,M 等参数下 d→0 时才可忽略该低阶项。
7. 精确有限 LP 用模型相关终点失败指标，而不是用平均未决面积替代概率约束。数值解另恢复共同动作策略，逐环境前向检查。
8. 随机标量、预算整除与配额边界检查共 20,000 组，全部通过；ABM 10,000 轮实现诊断；实际交互 API 与测试引擎累计 112,000 轮逐动作、服务标志和终身计数完全相同。

## 算法路线

| 路线 | 具体实现 | 结果与处理 |
|---|---|---|
| 同一证据的多个报告收益 | Bundle 20–25，按预测完成数/连续进展给证书成本折价 | 开发上部分配置小改善；独立测试未建立优于 CCP 的普遍优势 |
| 共享端点边际优先级 | Shared 26–29，按全部当前证书的边际收益累计端点分数 | 28 为预冻结主候选；测试面积平均 -0.39%、regret +1.98% 相对 CCP，不更换默认推荐 |
| 标签向量信息增益 | 48 次 Beta 粒子，按潜在标签向量分组估计互信息 | 具体开发实现未胜出；不等同于精确 IDS，也不否定整个 IDS 家族 |
| 共同凸规划 | 当前全部阻塞对约束，坐标对偶迭代、四种取样规则 | 部分 regret 低但面积明显较差；局部代理可行/最优不是统计前沿 |
| 多见证优化与收益核切换 | 36–40，候选负证据遍历参照；UCB/MOSS、TS、KL 组合 | 后续开发探查只有很小或不稳定改进，没有独立确认，不升格为新方法主张 |
| 按激活预算的细任务 | ABM | 理论上闭合受限更新族的大段中间预算；仅实现检查，无实用优势实验 |
| 全部行为策略优化 | 固定有限模型 LP；一般有限树半无限 LP | 小模型前沿确实求解；不提供大规模未知未来算法 |

## 实验版本与异常

- 开发 round1：384 条轨迹；round2 有效重跑：192 条。
- round2 首次运行遇到 Numba 对跨模块依赖的旧缓存，使新模式退回原分支。该 192 条无效运行保存在 `development-round2-invalid-stale-cache*.csv`，不计入有效开发或测试统计。清理缓存后使用原相同开发种子完整重跑。
- 主候选与 12 新测试环境/22配置/48重复在 `holdout-freeze.json` 冻结，SHA-256 检查通过。12,672 条测试完整保留，无测试后调参。
- 查看主测试后又做 672 条仅在原 DEV 环境的开发 round3，探索多见证与收益核。它们不是独立测试、没有替换预冻结主候选，没有作为“最终胜出”的证据。
- 实用 API 检查曾仅在保存 JSON 时遇到 NumPy int64 序列化错误；修正显式 int/float 后完整重跑。采样逻辑未因此改变。
- 精确前沿早期 ε=.8 的小模型大部分预算不可行；T=12 一次 HiGHS 数值状态未闭合，保留 `exact-wide-static-binary.log`，不把该状态声称为数学不可行。另以 ε=.95 的明确诊断模型成功求解非平凡前沿。两个模型的结果不混用。
- 所有失败覆盖/空交集路径保留在结果里。不同方法共享潜在奖励流；跨方法不是独立样本。均值对照使用每个环境内部配对差。

## 尚未闭合的最小接口

1. 在明确的未知未来日程类、同一信息条件下，给出可计算、非循环的完整因果联合复杂度，并由一个高效策略达到。
2. 将 ABM 的受限族匹配推进至任意重叠到达、异质边界距离、a<Amin 与延迟端；不能省略 R0 或粗精度 v 的校准。
3. 为 CCP 的真实证书完成时间而非不变中心/平方根半径代理证明逼近界。
4. 将工程改进在更强原版/忠实适配的 ALL-epsilon 方法及更大臂集上验证。当前 ALLplus 是明确的自然适配，不是 FAREAST/(ST)^2 的原版代码。

本轮没有独立子代理、外部同行或形式化证明系统复核。解析证明是理论依据；诊断只帮助定位转写/实现错误。
