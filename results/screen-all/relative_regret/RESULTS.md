# 全 setting 缩小研究：实际数值结论

已完成 45 个来源布局、540 个布局—奖励分布组合、40 个方法配置、每单元 4 次配对重复，共 **86,400 条唯一轨迹**。所有布局缩到 T=400，实际臂数见下表；原规模正式主实验尚未运行。算法核心与基线公式未调参。

主热图比较关闭专门分类服务的 SRC-R、SRC-KL-R 与 22 个 baseline。全部正分类偏好、area 与匹配控制也已运行，其 21,600 个单元均值保存在 `all_cell_methods.csv`。

## 两种算法之间的差别

| 来源组／实际规模 | SRC-R 平均 regret | SRC-KL-R 平均 regret | KL 相对原 SRC |
| --- | ---: | ---: | ---: |
| F17，K=2–20 | 8.92 | 16.55 | +85.5% |
| adaptive，K=2–28 | 11.34 | 18.10 | +59.7% |
| dense，原 K100 → 实际 K20–30 | 22.44 | 29.40 | +31.0% |
| dense，原 K500 → 实际 K40 | 37.61 | 40.46 | +7.6% |
| dense，原 K2000 → 实际 K80 | 59.94 | 50.94 | -15.0% |
| scale，原 K4000 → 实际 K100 | 80.00 | 60.28 | -24.7% |
| 全部 540 cells 等权，主要口径 | 19.65 | 24.40 | +24.2% |
| 六个来源 section 等权，敏感性口径 | 36.71 | 35.95 | -2.1% |

KL 改进版在这次短时域比较中没有全面优于原 SRC：低密度与少臂设置成本更高，高密度和 scale 则更低。理论的长期 KL 常数改善不能被直接解释成 T=400 的普遍数值改善。

全部 cells 等权时，F17 与 adaptive 占 384/540 个组合；六个 section 等权时高密度和 scale 的相对影响更大，因此两算法的总体排序会变化。两个权重口径均在运行前确定，未根据结果挑选。

## 相对其他算法

主要口径下，SRC-R 与 SRC-KL-R 的平均 regret 均低于全部 22 个 baseline。相对 IMED 的变化分别为 **-23.1%** 与 **-4.5%**。主要口径下最低的 baseline 均值为 Clipped-ACI 的 25.47。

这不表示每个 setting 都获胜。逐单元比较四次重复的平均值，SRC-R 在 **337/540** 个组合低于所有 22 个 baseline，SRC-KL-R 为 **42/540**。这些是描述性点估计计数，不是同时显著性胜出数。

高密度尤其存在明确反例：实际 K80 时 SRC-R/SRC-KL-R 相对 BL-MOSS-b2 分别高约 41.5%/20.3%；实际 K100 的 scale 分别高约 46.7%/10.5%。BL-MOSS 额外知道 horizon，其信息条件已在方法表单列。
