# 全 setting 缩小比较结果

本轮采用当前数值核与源码指纹隔离的 Numba 缓存重新模拟：45 个来源布局、540 个单元、每单元 4 次配对重复、37 个配置（19 个奖励 baseline），共 79,920 条唯一轨迹。时域统一为 T=400；原规模正式矩阵未运行。

下表为相对 IMED 的宏平均动态 regret 变化。负值表示更低；百分比是单元等权宏均值之比，不是逐单元百分比的平均。

| 来源组 | SRC-R | SRC-KL-R（默认） |
| --- | ---: | ---: |
| F17 | -25.9% | +37.4% |
| adaptive | -24.2% | +20.5% |
| dense K100→20–30 | -25.9% | -5.4% |
| dense K500→40 | -23.5% | -18.9% |
| dense K2000→80 | -19.0% | -31.8% |
| scale K4000→100 | -15.0% | -35.9% |
| 全部单元等权 | -22.4% | -4.5% |
| 六个来源组等权 | -19.8% | -22.1% |

![两种默认奖励端点相对19个baseline](relative_regret_screen.png)

SRC-KL-R 的默认奖励上限在 F17/adaptive 上表现较弱，在更密集到达与 scale 派生组上更好；两种总体权重都保留。不能从某个总体百分比推出每个 setting 都更好。

这些是缩小环境上的描述性结果，未绘显著性星号；配对 delta-method t 区间保存在 [percent_matrix.csv](percent_matrix.csv)。全部 37 个配置的逐单元表见 [all_cell_methods.csv](all_cell_methods.csv)。206 条 coverage 标记完整保留，错误标签和空交集标记为 0；没有按胜负或失败情况删除路径。

保留了来源布局与实际布局的映射。F17/adaptive 保留原臂数但缩短时域与到达时刻；dense/scale 还减少了臂数。本结果不能充当原 T、原 K 的测量。

仅改变 SRC-KL 固定奖励参数的原尺寸验证另见 [参数检查](../../parameter-check/RESULTS.md)，不与本表混合计数。
